# Predictive Maintenance using LSTM

This project predicts the Remaining Useful Life (RUL) of aircraft engines using the NASA C-MAPSS FD001 dataset.

## Technologies
- Python
- TensorFlow/Keras
- LSTM
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Model Performance
- MAE: 38.18
- RMSE: 42.55

## Dataset
NASA C-MAPSS FD001
